# Planner

This repository is intended to be a personal planning workspace for organizing schedules, tasks, and day-to-day priorities.

## Purpose

The repo will store Markdown (`.md`) or plain text (`.txt`) files that describe:

- Working schedules and availability
- Daily, weekly, or monthly plans
- To-do items and task lists
- Deadlines and due dates
- Priorities and urgency levels
- Notes or context needed to plan the day

The goal is to keep planning information in simple text-based files so it is easy to read, update, version, and reuse.

## How This Repository Will Be Used

I plan to use this repository together with an AI assistant to create practical daily schedules. The assistant can review the planning files in the repo, understand my commitments and priorities, and then help generate a schedule for the day.

A typical workflow may look like this:

1. Add or update schedule, task, and planning files.
2. Include deadlines, estimated effort, and priority where useful.
3. Ask the assistant to review the files.
4. Generate a focused day plan that balances work, deadlines, priorities, and available time.

## Suggested File Organization

Possible files or folders may include:

```text
schedule.md        # Regular working schedule and availability
tasks.md           # Current to-do list with deadlines and priorities
plans.md           # Short-term or long-term plans
notes.md           # Extra context for planning
archive/           # Completed or outdated planning files
```

This structure can evolve over time as the planning process becomes clearer.

## Task Details to Track

For best results, tasks can include details such as:

- Task name
- Deadline or target date
- Priority level
- Estimated time required
- Dependencies or blockers
- Notes about context or desired outcome

Example:

```markdown
- [ ] Finish project proposal
  - Deadline: Friday
  - Priority: High
  - Estimated time: 2 hours
  - Notes: Needs review before sending
```

## Goal

The main goal of this repository is to provide a clear, text-based source of truth for schedule planning so each day can be planned around the most important commitments, deadlines, and priorities.
